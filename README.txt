# RE:EARTH — Climate Change & Environmental Sustainability

## File index
- `index.html` — Main homepage
- `styles.css` — Visual design, responsive layout and animations
- `script.js` — Interactive buttons, impact cards, action selector, mobile menu and scroll progress
- `assets/` — Images supplied for the homepage

## How to open
Keep the files in the same folder structure, then double-click `index.html`.
No server or installation is required for this homepage.

## Homepage features
- Full-screen visual hero
- Scroll progress indicator
- Responsive navigation/mobile menu
- Interactive “Show me a fact” button
- Four clickable environmental impact cards
- Interactive personal action selector
- Responsive/mobile-friendly layout
